## 1. 研究概要と設計の状態

本研究は、自然な対話における顔運動を対象に、ある部位の過去が別の部位の次時点の運動を予測する情報を持つか、その情報が学習に含まれない被験者にもどの程度共通するかを調べる。対象部位自身の履歴による予測を基準に、他部位の履歴を加えたときの誤差減少を、すべての部位対と時間差について評価する。PCMCI+による関係の選択は、その予測上の価値と安定性を併せて調べる。

本書は、研究目的、対象データ、測定、分割、学習、評価、集約、図表、実行手順、完了条件を一つに定める。他の計画書の定義を補読する必要はない。

| 状態 | 内容 |
|---|---|
| 設計の基礎となる方針 | 集団の共通性、正規化変位、点ごとの平均ユークリッド誤差、被験者・対話groupを分離した評価、全候補の予測情報、PCMCI+・ParCorr・Ridge、1フレーム先予測 |
| 本書で具体化する設計案 | NoXi、測定点、品質閾値、校正、履歴決定手順、探索と学習の詳細、中心化幅、統計・図表の規則。数値と手順は実データ確認前の設計値であり、承認・検証・凍結済みの値とは扱わない |
| 本実験開始前に登録する実値 | データ配布版と利用条件、ファイルとモデルのhash、実fps、適格人数、分割、採用Self履歴、alpha候補、品質確認と実行検証の結果 |

以下は一つの実行案として記述する。設計値の採否は予備データによる確認を経て本実験の評価前に固定し、評価結果を根拠に選び直さない。開始前に必要な確認と証拠は第18節に集約する。

## 2. 研究の問いと実施範囲

主たる問いは、①どの部位対に追加予測情報があるか、②どの時間帯に分布するか、③被験者間で符号と大きさがどの程度共通するか、の三つとする。

| 必須解析 | 評価する内容 | 主な出力 |
|---|---|---|
| 全候補Landscape | Self履歴を超える追加予測情報の分布 | 全cellのG、部位対×lag帯域の集団要約 |
| 被験者間の共通性 | 集団の典型値、改善方向の共通性、個人差 | 被験者別G、G>0割合、人数・group数 |
| 4モデル比較 | 持続予測、Self、Full、PCMCI-blockの誤差と入力規模 | 被験者別誤差、対応差、入力数 |
| Selection enrichment | 選択集合が同じ入力規模の集合より高いcell-Gを含むか | 1,000ランダム集合、集合平均、Enrichment |
| 選択lag中心の応答 | 選択lagから時間位置をずらしたときの誤差変化 | 絶対lag曲線、中心化曲線、対象集合 |
| 発見安定性 | 学習する集団の構成による選択の変動 | 100回の再探索、選択頻度と分母 |
| データ・実行監査 | 測定品質、評価可能範囲、計算と再生成の正しさ | 品質記録、support、失敗台帳、結果manifest |

本実験の完了範囲は上表とする。効果が正であること、有意差、予測性能の最高値、Fullとの同等性、一定の疎性は完了条件にしない。

対象とする関係は、観測された顔運動の遅延予測依存および条件付き依存である。PCMCI+の因果解釈には仮定が必要であり、矢印から直接的な筋肉間因果、lagから生理的伝達時間を結論しない。[PCMCI+原著](https://proceedings.mlr.press/v124/runge20a.html)

## 3. 記号と評価単位

| 記号・用語 | 定義 |
|---|---|
| s、c、k | 被験者、発話条件、outer-fold |
| i、j、p | source領域、target領域、顔の測定点 |
| f | 採用データのフレームレート（frame/秒） |
| t、u | 予測起点tと予測対象時点u=t+1 |
| τ | target時点から遡るlag。入力時点はu−τ。τ=1は予測起点tの現在観測 |
| H、L | Selfの最大履歴長と他部位の最大lag。単位はframe |
| q、q_ref、d | 幾何学的正規化座標、個人の固定基準形状、変位d=q−q_ref |
| ブロック | 一つのsource領域の、あるlagにおける全採用点のx・y成分 |
| cell e=(i,j,τ) | Selfへ一つのsource領域×lagブロックを追加する比較単位。i≠j |
| Ω | すべての領域間cellからなる候補集合 |
| support U | モデル間で共通に用いる予測対象時点の集合。行ID・点集合・hashを持つ |
| 独立group | 同一人物、対話ペア、共有セッションでつながる記録の連結成分 |
| OOF結果 | 各被験者を学習から外したouter-foldで得た評価結果 |

被験者を集団要約の基本単位とする。記録、frame、cell、ランダム反復、foldを独立した被験者として数えない。groupは分割と再標本化で依存関係を保持する単位として用いる。

## 4. データと発話条件

### 4.1 対象データ

主データの第一候補は、原映像・音声・注釈を含むNoXiの単一配布版とする。NoXiは自然な二者対話を扱い、配布元は映像・音声・注釈の提供を案内している。[NoXi配布元](https://multimediate-challenge.org/datasets/Dataset_NoXi/)

実際の利用許可、取得、配布版の確認は未完了として扱う。異なるコーパスや配布版を混合せず、取得ファイルから被験者・group・session・sequenceを識別し、実IDで人数を数える。単一話者のデータは集団実験の対象にしない。

必須の入力情報は、原映像の時刻とfps、画像寸法、顔の可視性、本人音声との同期、被験者・対話相手・共有セッション、発話注釈、前処理の由来、利用条件への参照とする。同じ人が複数の相手と参加した場合は、関連する人とセッションをすべて同じgroupへまとめる。

### 4.2 解析条件

| 条件 | 含める状態 |
|---|---|
| 本人のみ発話 | 本人が言語的に発話し、相手は発話していない区間 |
| 本人非発話 | 相手のみ発話する聞き手状態、および双方非発話。両状態のflagと時間は個別保存 |

重複発話、本人の笑い・咳等の非言語音、不明区間・移行区間は注釈として保存し、学習と評価から除く。発話境界の前後200 msを除外し、最も古い入力からtargetまで同じ解析条件が続く行だけを使う。短い区間を連結しない。

条件は本人音声に基づく人手確認済み注釈で定める。既存注釈がなければ自動音声検出を下書きに用い、開始・終了、話者、非言語音を人手確認する。口の運動から発話条件を選ばない。

二つの条件で探索と予測を別々に行い、分割は共有する。条件差の検定や条件間転用は本実験に含めない。一方だけ成立する被験者・条件の結果も残す。「本人非発話」は中立・安静・表情ありを意味しない。

## 5. 予備解析、人数、データ分割

### 5.1 予備解析と適格性

共通seedを20260911とし、用途、fold、条件、target、反復を名前で区別する。空でない用途keyの前後空白を除き、文字列`20260911:{key}`をUTF-8で符号化してSHA-256を計算し、先頭4 byteをbig-endianの符号なし整数として派生seedにする。使用keyと実seedを保存する。

予測結果を見る前に独立groupをseedで並べ、合計5人以上に初めて達する最小のgroup集合を予備解析へ確保する。そのgroupの全関連記録を本実験から除く。予備解析には、点の位置と追跡品質、校正、Self履歴、alpha候補、計算量、実データdry runの確認を含める。大きいGや良い成績を示す部位・帯域を選ぶ用途には使わない。

本実験は、予備解析を除く適格被験者を原則全員使用し、人数の固定打切りを設けない。被験者・条件の適格性は、校正・QC・履歴・境界の除外後、候補領域に共通するsupportが合計60秒以上あることとする。outer-testではfold固有のmask適用後に30秒以上あることを評価の下限とする。有効時間は有効target行数/fで計算する。

60秒と30秒は運用上の下限であり、検出力や独立標本数を保証する値ではない。

### 5.2 Outer・inner分割

outerは独立group単位の5分割を1回、innerは各outer-train内のgroup単位3分割とする。各被験者はouter-testに1回だけ寄与する。同一人物・対話ペア・共有セッションの記録を分割しない。

割当ては、groupを「被験者数の降順、条件合計有効時間の降順、seedによる順」で処理する。各foldに最初の1 groupを順に置き、以後は追加後のfold間の被験者数および各条件有効時間の偏りの二乗和が最小になるfoldへ置く。各項は総量で割って無次元化し、同点はfold番号順とする。innerにも同じ規則を適用し、実際の割当てを保存する。

| 判定 | 実施規則 |
|---|---|
| 5分割の成立 | 各outer-testに2以上の適格groupがあり、各outer-trainのinner 3分割の各validationにも2以上の適格groupがある |
| 5分割で不足 | 同じ最低要件でouter 3分割を1回だけ試す。条件間で同じgroup割当てを維持する |
| 3分割でも不足 | 当該条件の集団実験は開始不可として記録する |

分割は人数と有効時間から決める。G、リンク、予測成績で割当てを調整しない。片方の条件が不足しても、その条件だけgroupを別foldへ移さない。innerはalpha調整に用い、独立した一般化性能の推定として報告しない。

## 6. 測定点、座標、個人校正

### 6.1 抽出器と主表現

主表現は、点ごとの2次元正規化変位d(p,t)=q(p,t)−q_ref(p)とする。各点のx・yを保持して入力・予測する。

抽出器の設計案はMediaPipe Face Landmarkerとし、IMAGEモード、num_faces=1、検出・presence閾値各0.5、BlendShapes出力無効、姿勢確認用の変換行列出力有効とする。各時刻の単一画像を処理する。公式APIのIMAGEモードは単一画像入力であり、VIDEO/LIVE_STREAMモードには追跡処理がある。[MediaPipe Python仕様](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python)

採用buildで画像の処理順序や過去・未来の画像への依存がないことを予備確認し、パッケージの厳密版、model assetのhash、点数・順序、全設定を固定する。抽出後に時間平滑化を追加しない。推定z座標は主入力に含めない。

### 6.2 領域と点の対応

8領域、29点、58成分を設計案とする。左右は解剖学的左右、点番号はMediaPipeの0始まりindexとする。

| 領域 | 点index | 点数 | x・y成分数 |
|---|---|---:|---:|
| 左眉 | 336, 296, 300 | 3 | 6 |
| 右眉 | 107, 66, 70 | 3 | 6 |
| 左眼瞼 | 385, 386, 380, 374 | 4 | 8 |
| 右眼瞼 | 158, 159, 153, 145 | 4 | 8 |
| 左頬 | 425, 280 | 2 | 4 |
| 右頬 | 205, 50 | 2 | 4 |
| 口 | 61, 291, 13, 14, 37, 267, 84, 314 | 8 | 16 |
| 顎 | 176, 152, 400 | 3 | 6 |
| 合計 |  | 29 | 58 |

採用modelの実出力と予備被験者の原画像への重ね描きで、位置・左右・遮蔽・追跡破綻を確認する。点番号だけで対応済みと判断しない。口角は左右の点を保持し、予測targetは「口」の1領域とする。各領域の全点を同時に予測し、領域重心やPCAへ圧縮しない。

### 6.3 幾何学的正規化

画像正規化座標のxに画像幅、yに画像高さを掛け、同じpixel単位へ戻す。右眼側33・133の平均をa_t、左眼側362・263の平均をb_tとし、次を定義する。

```math
c_t=(a_t+b_t)/2,\qquad s_t=\|b_t-a_t\|_2,
\qquad q(p,t)=R_t\{pixel(p,t)-c_t\}/s_t.
```

R_tはa_tからb_tへの線分を水平にする2次元回転とする。平行移動、画像内回転、全体スケールを補正し、局所変形を残す。単位は「眼角中点間距離に対する比」とする。参照眼角は解析点とは別に扱う。

参照点欠測、s_t≤0、画像上の参照距離20 pixel未満はframe無効とする。参照点を自動置換しない。全顔の非剛体な合わせ込みは行わない。

### 6.4 個人校正

被験者ごとに最初の記録から、最初に得られる品質適格な連続10秒を校正区間として確保する。各点のqのx・yそれぞれの時間中央値をq_refとする。先行区間と校正区間は学習・評価から除く。連続10秒を確保できない被験者は校正不能とする。

q_refは以後固定し、評価記録全体から更新しない。この形状は個人の代表形状と呼ぶ。評価は「他者から学習したモデルに、対象者の事前の短い校正を与える条件」として報告する。

## 7. 時刻、品質、使用可能領域

原fpsを維持する。複数cadenceがある場合、適格被験者が最も多いcadence層を主対象とし、同数なら被験者総有効時間、さらに同数なら低いfpsで決める。metadataと品質・有効時間のみで選び、異なるfpsを同じframe-lag探索へ混ぜない。

| 対象 | 処理規則 |
|---|---|
| 時刻 | 単調増加を必須とする。期待間隔1/fから5%を超えるずれ、欠落frame、重複時刻、映像カット、条件変更は連続区間の境界 |
| 欠測 | 非有限値、画像外の解析点、顔未検出、明瞭な遮蔽を無効化。点のx・yを一組でmaskし、点・領域別の理由を保存 |
| 姿勢 | 採用buildで姿勢軸を確認し、絶対yawまたはpitchが20度を超えるframe、姿勢推定不能frameを除外。rollは2次元回転で補正 |
| 時間処理 | 再サンプリング、欠損補間、追加時間平滑化、差分化、トレンド除去を行わず、欠損を詰めて隣接扱いにしない |
| 運動量 | 大振幅・高速度だけで外れ値除去せず、低運動だけで被験者を除外しない |
| 点confidence | 採用APIが出力する情報のみ使用。存在しない点confidenceを仮定しない |

各outer-trainで、学習可能な被験者の80%以上に有効データがあり、被験者内分散を等重み平均したx・yの分散がともに10^-12を超える点を使用可能とする。これは数値退化の判定である。

点の使用可能性は、成立する各条件のtrain側判定の共通集合として固定する。領域内に一つでも使用不能点があれば、そのfoldの領域全体を使用不能とする。全モデル・cell・testで同じmaskを使い、点を減らしたtargetへ読み替えない。inner-trainで退化する入力列はそこで定数列として除き、同じ変換をinner-validationに適用する。

元の候補台帳には全領域・全cellを残し、使用不能領域を含むcellを評価不能として記録する。testの低分散や成績を理由にmaskを作り直さない。

品質閾値は予備確認の対象である。実画像の低運動・発話・頭部回転・遮蔽を確認し、欠損率、変位振幅、追跡品質を保存する。小振幅を測定精度の証拠とせず、計測の限界を結果と併記する。

## 8. 時間範囲とSelf履歴

予測は1フレーム先、u=t+1とする。他部位の最大lagはL=⌊0.5f⌋ frame、候補はτ=1,…,Lの全整数とする。各lagには1000τ/f msを併記し、実際の上限1000L/f msを報告する。

帯域はB1=(0,100]、B2=(100,250]、B3=(250,500] msとし、実msから整数lagを割り当てる。帯域内lag数を保存し、空帯域は評価不能とする。探索上限でGが最大でも、その位置を最適lagや効果の終端と断定しない。

Selfはtarget領域の全点のx・yについてτ=1,…,Hを使う。Hは予備被験者だけで次の順に決める。

1. 0.5、1、2秒の履歴を比較し、frame数は⌊f×秒⌋とする。予備記録を時系列順に60%学習、20%alpha選択、20%履歴比較へ分け、境界から最大履歴分を除外する。各候補を同じ時点・targetで比較する。
2. 主誤差を時点、領域、被験者、成立する条件の順で等重み集約し、最良誤差の1.01倍以内にある最短履歴を採る。
3. 2秒が1秒より1%以上良い場合に限り4秒を追加し、全候補を4秒履歴に対応する共通supportで再比較する。4秒が2秒よりさらに1%以上良ければ、Selfの飽和未確認として開始前に設計を見直す。
4. 一つのHを全fold・全条件・全モデルに共通適用する。

1%は予備Self誤差の近似同点規則とする。必要な連続時間がなければ確認未完了とする。fps、H、L、各帯域と中心化gridの実frame・msを実行設定へ登録する。

## 9. PCMCI+と選択ブロック

### 9.1 探索設定

Tigramite 5.2.10.1、PCMCI+、ParCorrを設計版とする。実行環境の厳密版と設定を保存し、使用APIとの一致を本実験前に検証する。

| 項目 | 設定 |
|---|---|
| scalar node | 点×座標。各点のx・yは別node |
| ParCorr | significance=analytic、mask_type=xyz、recycle_residuals=False |
| 閾値 | pc_alpha=0.01固定 |
| 探索範囲 | tau_min=0、tau_max=L |
| 同時刻 | 探索で考慮しraw結果を保存。予測入力はτ≥1 |
| Collider・衝突 | contemp_collider_rule=majority、conflict_resolution=True |
| その他 | reset_lagged_links=False、max_combinations=1。max_conds_dim、max_conds_py、max_conds_px、max_conds_px_laggedはすべてNone |
| 内部多重補正 | fdr_method=none |
| 事前リンク制約 | 追加しない |

各被験者・session・連続区間を別seriesとして渡し、境界をまたがない。発話条件ごとに探索する。被験者ごとの探索用有効target行数は、そのouter-train・条件の最短の適格被験者にそろえる。各人の区間を時刻順に取り、Tigramiteの履歴cut-offを反映した行数で上限を適用する。履歴用の先行frameを保持し、採用行を詰めて新系列にしない。

raw graph、p_matrix、val_matrix、scalar node対応、実際に使った系列と行を保存する。pc_alphaと内部p値は探索設定・探索出力として扱う。

### 9.2 候補とブロックへの投影

候補Ωは、i≠jのすべての領域対とτ=1,…,Lの組合せとする。8領域の場合は56L cellである。PCMCI+の選択が空でも、使用可能な全候補のcellモデルを評価する。

あるlagにおいて、source領域のいずれかのscalarからtarget領域のいずれかのscalarへ有向リンクが1本以上あれば、その領域対×lagブロックを選択する。重複を一つにまとめ、曖昧・衝突した印は有向リンクとして採用しない。

予測には選択ブロック内の全採用x・y成分を追加する。rawのscalarリンクとブロックへのOR投影を両方保存する。ブロックの選択を、全scalarリンクの発見とは表現しない。

探索はouter-train全体で1回行い、親集合を固定してinnerではalphaのみを調整する。このinnerスコアは探索から独立した性能評価ではなく、外部への一般化はouter-testの結果で評価する。

## 10. 予測モデルと学習

### 10.1 比較するモデル

| モデル | 予測・入力 |
|---|---|
| Persistence | d̂(p,u)=d(p,u−1) |
| Self | target領域のτ=1,…,Hの履歴 |
| Full | Self＋すべての使用可能source領域のτ=1,…,Lのブロック |
| PCMCI-block | Self＋PCMCI+で選択した領域×lagブロックの和集合 |
| cellモデル | Self＋一つのsource領域×lagブロック |

Persistence以外は、target領域の全x・y変位を同時に出力するRidgeとする。Self履歴は常に共通に含める。空選択のPCMCI-blockはSelfの予測を再利用する。

### 10.2 標準化、損失、alpha

Ridgeは切片あり、切片を罰しない。targetの変位尺度を維持し、入力のみ学習データで標準化する。被験者sの各有効行に重み1/n_sを与え、各被験者の総重みを1とする。この重みを入力の平均・分散とRidge損失の両方へ適用する。

```math
\min_{B,b}\ \sum_{s\in train}\frac{1}{n_s}
\sum_{u\in U_s}\|y_{s,u}-B^\top z_{s,u}-b\|_2^2
+\alpha\|B\|_F^2.
```

zは被験者等重みでpoolした学習平均・分散による標準化入力、yはtarget領域の変位ベクトルとする。Ridgeの二乗損失と主評価の平均ユークリッド誤差は区別する。

標準化は各inner-trainでfitし、alpha選択後にouter-trainでfitし直す。評価被験者の記録全体から平均・分散を推定しない。

alphaは10^-4、10^-3、…、10^4の9候補とし、条件・target・モデル・cellごとに個別選択する。一つのモデルの全出力に同じalphaを使う。inner-validation被験者それぞれの主誤差を1回ずつ数えた等重み平均が最小の候補を選び、差が10^-12以下の数値同点だけ大きいalphaを採る。

予備解析で端のalphaが隣接候補より1%以上良いモデルがあれば、その側へ10倍ずつ、全モデル共通gridを各側3段階まで拡張する。改善がなお端へ続けば計算設定を見直す。予備で使用したモデル種・条件と採用gridを記録する。

### 10.3 共通support

条件・fold・被験者ごとに一つのsupportを固定する。使用可能な全領域の他部位lag、Self履歴、target点が揃い、入力の最古時点からtargetまで同一条件・同一連続区間に収まるtarget行の共通集合とする。trainと各inner partitionにも同じ規則を適用する。

4モデル、全cell、Enrichment、中心化曲線に同じ行と点集合を用いる。support ID/hashが一致するときにSelf誤差とcell予測を再利用する。行数だけの一致では比較を認めない。

使用不能領域はfoldのmaskで識別する。成立するtarget別結果は残し、全顔要約は8領域すべてを評価可能な被験者に限る。共通support不足を理由に結果を見てcell別supportへ切り替えない。工程ごとの失われた時間と採用可能率を報告する。

## 11. 主指標、Landscape、モデル間の対応差

### 11.1 主誤差

被験者s、条件c、target領域j、モデルmの主誤差を次で定義する。P_jはtargetの固定点集合、Uは共通supportとする。

```math
E_m(s,c,j)=\frac{1}{|U|}\sum_{u\in U}\frac{1}{|P_j|}
\sum_{p\in P_j}\sqrt{(\widehat d_{m,x}(p,u)-d_x(p,u))^2
+(\widehat d_{m,y}(p,u)-d_y(p,u))^2}.
```

各点のx・yのユークリッド距離を計算し、点と時点を等重み平均する。被験者内の全適格sequenceを通じて時点を平均するため、長いsequenceの寄与は大きくなる。被験者間の集約では記録時間による重みを付けない。全顔は被験者内で8領域を等重み平均する。

Eの単位は眼角中点間距離に対する比で、小さいほどよい。指標IDは`displacement_mean_euclidean_error`とする。図表で×10^-3表示を用いる場合は軸へ明記する。

### 11.2 全候補のG

```math
G_{s,c}(i,j,\tau)=E_{Self}(s,c,j)-E_{cell}(s,c,i,j,\tau).
```

正は改善、負は悪化とする。例えば同一supportでE_Self=0.020、E_cell=0.018ならG=0.002である。GはSelfへ一つのブロックを加える予測価値であり、他の全領域を条件づけた直接効果ではない。

帯域内の全lagのGを被験者内で等重み平均し、その後に被験者間中央値を求める。帯域内の一部lagが計算失敗した場合、成功lagだけで帯域平均を代用しない。

各部位対×帯域に、中央値、平均、G>0の人数と割合、評価人数、独立group数、名目95% bootstrap区間、点集合、lag数を保存する。G=0は正の人数に含めず、評価不能は割合の分母へ含めない。部位対の直接比較は共通被験者の対応差から計算する。

### 11.3 4モデルの比較

各被験者・targetのEに加え、次の対応差を保存する。被験者ごとに差を計算してから集団要約し、モデル別の集団中央値を引いて対応差としない。

| 対応差 | 正の意味 |
|---|---|
| E_Persistence−E_Self | Self履歴で持続予測を改善 |
| E_Self−E_Full | 全他部位履歴の追加で改善 |
| E_Self−E_PCMCI-block | 選択ブロックの同時入力で改善 |
| E_Full−E_PCMCI-block | PCMCI-blockがFullより低誤差 |

入力規模は、Self scalar列数、追加ブロック数、追加scalar列数をfold・target別に保存する。cell-Gを足し合わせて同時入力モデルの利得にしない。

## 12. Selection enrichment

fold・条件・target jの選択集合をS_jとし、使用可能なsource領域×lagブロック全体を抽出母集団とする。Selfは抽出しない。

1. ブロックの実scalar成分数dで母集団と選択集合を層別し、各層の選択ブロック数k_dを数える。
2. 各層の全候補からk_d個を一様・非復元抽出し、合わせてランダム集合A_j,rを作る。
3. 1,000回繰り返す。集合内重複は禁止し、選択集合との重なりと反復間の同一集合は許可する。候補数=k_dの層では全候補を採る。
4. lag分布は一致させず、ブロック数と実scalar成分数を一致させる。
5. 集合をouter-trainで生成・固定し、同じfoldの全test被験者に共用する。

```math
A_{sel}(s,j)=\frac{1}{|S_j|}\sum_{e\in S_j}G_s(e),\qquad
A_{rand}(s,j,r)=\frac{1}{|A_{j,r}|}\sum_{e\in A_{j,r}}G_s(e),
```

```math
Z_{s,j}=A_{sel}(s,j)-\frac{1}{1000}\sum_{r=1}^{1000}A_{rand}(s,j,r).
```

ZをEnrichmentと呼ぶ。target別結果を保存し、被験者内で空でなく評価可能な選択targetのZを等重み平均してから被験者間中央値を計算する。fold別のtarget集合を明記し、この集約を「評価可能な選択targetの要約」と呼ぶ。

1,000反復の集合ID、構成、seed、各被験者・targetのA_randを保存する。必要なcellや反復が欠けた場合、成功分だけで1,000回平均を代用しない。

空選択はEnrichment評価不能とする。全集合が選択された場合はZ=0とし、選択の識別余地がないことを記載する。ランダム集合の順位を厳密な置換p値として扱わない。Z>0でもA_sel<0なら、Selfに対する予測改善とは結論しない。

本解析は計算済みcell-Gの集合平均の比較であり、1,000集合のRidge再学習は行わない。

## 13. 絶対lagと選択lag中心の応答

全候補について絶対lagに沿ったG、E_cell、E_Selfと被験者別曲線を保存する。その上で、選択edge e=(fold, condition, i, j, τ*)を中心化する。

中心化の設計幅は約±100 ms、M=⌊0.1f⌋、Δ=−M,…,0,…,+M frameとする。実幅は1000M/f msを報告し、M=0なら中心化解析不能とする。

全Δで1≤τ*+Δ≤Lとなるedgeだけを対象とする。境界のclip・wrap、片側grid、Δごとのedge除外は行わない。中心化対象外も含め、選択された全edgeの絶対lagとGを保存する。

```math
D_{s,e}(\Delta)=E_s(i,j,\tau^*+\Delta)-E_s(i,j,\tau^*).
```

E_s(i,j,τ)はSelf＋当該source領域の単一τブロックの誤差である。Landscapeのcell予測を再利用し、alphaは各cellで選択した値を使う。

集約は、①同じ被験者・source→targetに属する複数選択lagのDを算術平均、②被験者内で部位対を等重み平均、③被験者間中央値、の順とする。全Δで同じedge・部位対・被験者・supportを使う。途中の計算失敗があれば、完全gridを満たさない結果を通常の曲線として受容しない。

正の応答はlagをずらすと悪化すること、負は周辺lagの方が低誤差であることを意味する。Δ=0は定義上0である。平坦なら時間幅を持つ関係として検討し、単一frameの特異性を主張しない。

全選択edge数、対称grid適格数、境界除外数・率、計算失敗数、部位対数、被験者数、group数を保存する。結果の適用範囲は、主lag範囲内で対称比較可能だった選択edgeに限定する。

## 14. 集団要約、不確かさ、発見安定性

### 14.1 統計の方針

本書の統計案は効果量と分布の推定を目的とし、held-outの有意性検定・FDR判定を行わない。PCMCI+内部の探索p値は別に保存する。集団の共通性は中央値、平均、正の割合、被験者別分布、人数から記述する。

outer-fold間で学習データが重なるため、OOF誤差を単純な独立標本とみなした不確かさの評価には限界がある。[Bengio & Grandvalet, 2004](https://jmlr.org/papers/v5/grandvalet04a.html)

### 14.2 集団要約のbootstrap区間

凍結したOOF結果を用い、各outer-fold内で独立groupを復元抽出する。各foldのgroup数を保ち、選ばれたgroupの全被験者・全cell・全曲線を一緒に取り出す。同じgroupが複数回引かれた場合もその多重度を保持する。

点推定と同じ順序で10,000回集約し、線形補間方式の2.5・97.5パーセンタイルを報告する。全図表で同じgroup抽出indexを共用する。各解析の評価可能性maskを保持し、評価不能値を0へ置換しない。必要な集約単位を作れない抽出がある場合はその事実を記録し、成功抽出だけで通常の区間にしない。

区間名は「固定したOOF結果に対する、被験者構成の変動を示す名目95% bootstrap区間」とする。探索・学習をやり直す変動を含まず、真の95%被覆を保証しない。曲線の区間は点ごとの区間であり、同時区間・多重比較補正済み区間ではない。

評価可能な独立groupが10未満なら点推定と個別値を示し、区間は少数groupのため評価不能とする。この10は運用上の報告基準である。frame・edge・ランダム集合を再標本化単位にしない。

### 14.3 発見安定性

各outer-train・条件で独立groupを復元抽出し、100回PCMCI+を再実行する。各groupに属する被験者の全seriesをまとめて扱い、系列内の時間順序を保持する。重複抽出したgroupは別のseriesコピーとして渡し、コピー同士を連結しない。

point maskと等時間の採用区間は元outer-trainで固定したものを維持する。scalarリンク、領域×lagブロック、領域対×帯域の選択を保存する。ブロックは第9節のOR投影、帯域は帯域内に一つ以上の選択ブロックがあることを選択と定義する。

本選択には元outer-trainの探索結果を使い、安定性頻度による足切りを設けない。各候補について予定反復数、選択可能反復数N、成功数、選択数k、失敗数n_failedを保存する。

| 状態 | 報告 |
|---|---|
| 全対象反復成功 | 選択頻度k/N |
| 失敗が残る | 不明幅[k/N, (k+n_failed)/N]。通常の頻度や95%区間とは呼ばない |
| N=0 | 評価不能 |

帯域内候補数も併記し、帯域幅による選択機会の違いを示す。fold間の選択出現も機会数とともに保存する。探索100回、Enrichmentの1,000集合、集団区間の10,000回はそれぞれ別の処理である。

## 16. 実験手順、保存、失敗処理

### 16.1 実行手順

1. **データ登録と予備分離**：利用条件、配布版、被験者・group・時刻を登録し、予備groupを分離する。
2. **測定と予備確認**：点mapping、校正、品質、時間処理、Self履歴、alpha候補、計算量、実データdry runを確認する。
3. **Protocol freeze**：第18節の確認を完了し、設計、実行設定、schema、split、環境、seedを一つの版として固定する。
4. **Outer-train処理**：点maskとsupport、等時間の探索、選択ブロック、innerでのalpha調整、outer-trainでの再学習、ランダム集合、100回の安定性探索を実行する。
5. **Fold lock**：前処理状態、候補と選択、全モデル・cellの学習結果、alpha、ランダム集合、対象行、設定をhash付きで固定する。
6. **Outer-test評価**：凍結した処理で4モデルと全cellを予測し、E、G、Enrichment、絶対lag・中心化応答を計算する。再探索・再tuningを行わない。
7. **集団集約と図表**：全被験者のOOF結果を統合し、bootstrap区間、図表、対象数、評価不能、失敗台帳を生成する。
8. **結果freeze**：必須出力の完全性と再生成を確認し、実在artifactとhashを結果manifestに固定する。

| 予測と解析 | 予測・正解・target時刻・点集合、support ID/hash、E、対応差、G、帯域値、集合構成と反復値、絶対/中心化曲線、選択頻度の分子・分母 |
| 集約と報告 | OOF被験者値、group抽出index、区間、人数、不能理由、数値表、図表とcaption、artifact registry、結果manifest |
| 実行状態 | 成功・評価不能・失敗の台帳、再試行記録、入力/config/code hash、検証結果 |

同じsupportのSelf・cell結果は参照で再利用する。すべてのモデルのファイル複製を必須にせず、保存した予測と再生成に必要な学習条件を保持する。集計値までの出典をIDとhashでたどれるようにする。

### 16.3 失敗と評価不能

| 状態 | 処理 |
|---|---|
| 選択集合が空 | PCMCI-blockはSelfへ縮退し、有効な予測結果として保存。Enrichment・中心化応答は評価不能 |
| 品質不適格・短時間・使用不能領域 | 事前規則に従い除外または評価不能。理由を保存し0で埋めない |
| 数値退化・ParCorrの自由度不足 | 学習不能。別検定や小さい条件集合へ自動変更しない |
| 一時的なI/O・実行失敗 | 同じ設定・seedで最大2回再試行し、初回を含む3回とも失敗ならfailedを残す |
| 入力・コード・設定の修正 | 版・hashを更新し、影響するfold・条件・cellをまとめて再計算する |
| 一部条件・targetだけ成立 | 成立する結果を残し、不成立部分の理由と対象数を示す |
| 原因不明の失敗・必要反復の欠落 | 当該解析は未完了。成功分だけを全反復の結果として扱わない |

再開時は入力・設定・コード・supportの一致を確認する。出力ファイルの存在だけで成功とせず、必要fold・cell・反復・Δの完全性を検証する。

## 17. 検証と実験の完了条件

本実験のouter-test評価前に、次の最小検証を完了する。

| 対象 | 確認内容 |
|---|---|
| 分離 | train/testのsubject・group非重複、予備group除外、校正と評価の分離、inner-trainだけでの標準化fit |
| 時系列 | h=1の入力時点、未来参照の不在、時刻・欠損・条件・sequence境界、既知lagの小さな例 |
| 測定 | 既知座標による移動・回転・スケール補正、点とx/yの対応、単位、mask、実画像との照合 |
| 主誤差とG | 点ごとの距離と平均順序、同一supportでの差、全候補保持、帯域内平均後の被験者中央値 |
| Enrichment | 1,000集合の完全性、層別のブロック数・scalar数、重複規則、集合平均、空集合・全集合の扱い |
| 中心化応答 | Self＋単一ブロック、完全対称grid、同じ対象集合とsupport、部位対を先に平均、Δ=0が0 |
| 安定性と区間 | groupと系列順序の保持、100/1,000/10,000回の用途、分母・失敗幅、同じ集約順、共用抽出index |
| 実行と図表 | 予備被験者での実データdry run、fold lock、失敗・再開、元artifactからの数値・図表再生成 |

例えば選択cell-Gが0.004と0.002なら選択平均は0.003、1,000ランダム集合平均の平均が0.001ならZ=0.002となる。同一部位対の2選択lagの応答が0.001と0.003なら部位対平均は0.002、別部位対の0.006と等重み平均した被験者値は0.004となる。こうした手計算可能な例で符号と順序を確認する。

実験完了には、全foldの必須解析が成功、または事前規則による評価不能として説明され、原因不明の失敗が残らず、必要な反復と対象集合が台帳で追跡でき、結果が元artifactから再生成できることを要する。評価不能で実施できなかった解析を実施済みとは報告しない。

仮説の支持と実験品質の受容は別に記録する。負のG、0付近のZ、平坦な中心化曲線も有効な結果として報告する。合成データは計算と表示の検証に用い、実データの効果量・人数・区間へ混入させない。

解釈の範囲は、採用データ、適格被験者、発話条件、可視性、測定表現、時間範囲、線形探索・予測器に限定する。G>0割合を真の効果を持つ人口の割合とみなさず、全員共通、直接因果、正確な伝達時間、モデル間の同等性をこの設計だけから主張しない。
