# サブシステムの価値評価と不採用判断

日付：2026-09-10。判断：**独立したmethodological validation subsystemは採用しない。正本から必須導入・専用benchmark・専用gateを削除し、必要な検証を既存の実装工程へ統合する。**

## 評価の基準

評価対象は検証一般の価値ではなく、現状の研究・既存コードに対して独立サブシステムを追加する限界的な価値である。今回のユーザー依頼「価値が低ければ削除したい」に基づき、前回の必須化を再評価した。

主判断は、本研究の主結果への寄与、既存検証との重複、既知の不具合を発見する能力、開発・維持負担、Primaryを遅らせる機会費用で行う。下記の高・中・低は相対評価であり、実測ROIや成功確率ではない。作業時間・実行時間は未測定で、日数や金額を精密に見積もれる段階ではない。

## 選択肢の比較

|案|追加証拠の価値|追加負担|Primaryとの関係|判断|
|---|---|---|---|---|
|3層の独立3Dサブシステムを必須導入|低〜中：観測変換には有用だが主仮説の証拠は限定的|高：asset、basis、逆写像、生成・観測grid、反復・report・gateの維持|新3解析より先に別の研究開発を抱える|削除|
|既存テストへ小さな既知例と不変条件を追加|高：方向・lag・mask・全候補・集約の誤りを直接検出|低〜中：実装する機能と同時に確認可能|P2〜P8の完成へ直接寄与|採用|
|合成・回帰検証をすべて削除|追加価値なし|短期は低いが不具合発見が遅れる|誤った評価計算を本実験へ持ち込む可能性|不採用|

## 判断を支えるローカル証拠

- `synthetic.py`はFaceTimeSeriesを直接生成する既存fixtureである。
- `test_pcmci_known_lag_validation.py`には既知のcross-region lagを探索・serializeする例がある。
- `test_synthetic_motion_validation.py`には少数点で局所運動と空間正規化を確認する例がある。
- `test_lane_a_contract_chain.py`にはquality→missingness→assemblyのmask維持の確認がある。
- `test_one_fold_scientific_dry_run.py`にはdiscovery、Ridge、Null、fold lockを接続する旧仕様の例がある。

これらは再利用可能性の証拠であり、今回テストを再実行したという意味ではない。旧100反復/common-shift等の実装を、新1,000反復/edge-centered解析の完成証拠にしない。

3D側には実データregion/anchor/topology未確定、位置→速度のgraph不変性、正規化のrank、積分漂流という未解決設計がある。追加することで検証対象そのものが増える。一方、新計画の全候補G、選択集合のenrichment、population応答はPrimaryに不可欠であり、こちらの計算・統合確認を先に進める方が投資効果が高い。

## 削除する範囲

独立subsystemの必須導入、468点canonical assetとbasisの新規実装、汎用安定VAR benchmark基盤、形態/head/noise全grid、専用Stage 1 freeze、MV-D1〜4、MV-G0〜6、専用受容reportをPrimary開始の条件から外す。これらのための新規開発を予定しない。

今回は関連コードを新規実装していなかったため、削除対象は文書上の要求・工程である。既存研究コードや有効なテストは削除しない。原添付文書と監査・反例の記録は履歴として残し、失効を明記する。

## 残す最小限の検証

1. 既存テストで方向・lag・単位・mask・subject/sequence境界・情報隔離を確認する。
2. 新landscape実装で、ParentSetが空でもΩが維持されることと、既知予測値からGを再計算できることを確認する。
3. 新enrichment実装で、1,000反復の完全性とcell集約/joint-model評価の区別を確認する。
4. 新population実装で、edge中心の整列、Δ=0、共通support、集約単位を確認する。
5. 本番と共通の新解析経路を小さな入力で接続確認し、実データdry run・科学監査へ進む。

これらは詳細設計T01〜T15、P2〜P8へ統合する。独立した合成論文規模のgraph性能評価・新たなgate体系を追加しない。実際に変更する前処理は、その変更を検証できる最小の既知座標例を持たせる。実データの品質・単位・時刻・適用範囲の確認はD01〜D10に残る。

## 判断の限界と再検討条件

独立3D試験を削ることで、形態・頭部運動・観測noiseの広い組合せに対する定量的な性能曲線は得られない。その範囲の頑健性を論文で主張しない。

将来、独立予備データで共通前処理の具体的な破綻が見つかり、小さな回帰例では原因を分離できない場合、または研究目的にgeometry/検出器の頑健性が明示的に加わった場合にのみ再検討する。再導入はその問題に必要な範囲から行い、今回の全面案を自動復活させない。

## 結論の確度

現時点の限界価値が低いという判断の確度は中程度。根拠は既存部品との重複と未完のPrimary機能であり、実データの観測問題を定量比較した結果ではない。作成済み文書の量や過去に必須化した事実は、継続投資の根拠にしない。
