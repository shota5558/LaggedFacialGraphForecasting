## 1. 新指標で区別する量

被験者s、発話条件c、target領域j、予測モデルmに対して、共通評価時点集合をU、targetの点集合をP_jとする。

```math
E_m(s,c,j)=\frac{1}{|U|}\sum_{u\in U}\frac{1}{|P_j|}\sum_{p\in P_j}
\sqrt{(\widehat d_{m,x}(p,u)-d_x(p,u))^2+(\widehat d_{m,y}(p,u)-d_y(p,u))^2}.
```

各点のx・yの距離を計算してから点・時点を平均する。座標成分ごとのRMSE、全点を連結したベクトルのノルム、領域重心の誤差とは異なる。幾何学的正規化後の変位尺度で評価し、入力標準化のz-scoreを誤差の単位にしない。

| 量 | 定義・正の意味 | 図表で答える問い |
|---|---|---|
| 主誤差E | 点ごとの平均ユークリッド誤差。小さいほどよい | 予測のずれはどれだけあるか |
| cell-G | E_Self − E_(Self＋source領域×lagブロック)。正ならそのブロックの追加で改善 | どのsource・target・時間帯に追加予測情報があるか |
| 同時入力モデルの対応差 | 例：E_Self − E_PCMCI-block。正ならPCMCI-blockが改善 | 選択ブロックをまとめて使う予測器は改善するか |
| Enrichment Z | 選択cell-Gの平均 − 同じブロック数・実成分数のランダム集合の平均Gの期待値推定 | 選択集合に高いcell-Gが集まるか |
| 中心化応答R | E_(Self＋block at τ*＋Δ) − E_(Self＋block at τ*)を所定順で集約。正ならずらすと悪化 | 選択lagの周辺に時間的位置の意味があるか |
| 正の被験者割合 | 帯域平均Gが0より大きい被験者数／評価可能被験者数 | 改善の符号が何人で共通するか |
| 発見選択頻度 | outer-trainのgroup再標本化で選択された回数と機会数 | 学習する集団の構成に選択がどれだけ依存するか |

最初の5量の単位は共通で、推薦正規化を採用する場合は「眼角中点間距離に対する比」。表示を `×10^-3` にそろえることはできるが、改善率%やmmとは表示しない。例えばE_Self=0.020、E_cell=0.018ならG=0.002、`×10^-3`表示なら2である。

cell-Gを足して同時入力モデルの改善量を作らない。選択頻度・PCMCIのリンク強度・G>0割合にも、それぞれ別の軸名と凡例を使う。G>0割合は「真の効果がある人口の割合」や各被験者の有意性を表す値ではない。

### N-F1：全候補Gを研究の入口にする

- 横軸source、縦軸target。左右は解剖学的左右とし、固定した領域順を全図で共用する。自己対は候補外として斜線、評価不能は灰色、観測G=0は発散色の中央色とする。
- 推薦8領域・3帯域なら、各条件につき56部位対×3帯域＝168セルをすべて示す。帯域は(0,100]、(100,250]、(250,500] msで、実fpsから入る整数lagを記録する。帯域数・領域数が改訂されたら実際の候補数を表示する。
- 被験者内で帯域内の全lagのGを等重み平均してから、被験者間中央値を取る。各lagの被験者中央値を先に計算して平均する方法へ入れ替えない。
- 色は0中心の発散色、全帯域・条件で共通範囲。上限は全表示値の最大絶対値を含むように機械的に設定し、負値を切らない。無効セルと低い値を同じ色にしない。
- 選択済みcellだけへの絞り込み、最大Gのlagだけの採用、区間が0をまたがないセルだけの表示はしない。PCMCIの選択状態はN-SF2で示す。

N-F1は各セルに適格な被験者の分布地図である。セル間で被験者集合が違う場合、色の大小だけで部位対の優劣を決めない。直接の差を述べる場合は共通被験者で対応差を別途計算し、元の地図と区別する。

### N-F2：共通性を平均的な改善と分けて見せる

本文の割合パネルはN-F1と同じ配置で0〜100%の固定尺度とし、セルには `正の人数/評価人数` を示す。G=0は正に数えず、評価不能は分母に入れない。独立group数は対応する数値表へ載せる。

被験者別Gは、固定された部位対の順×被験者のヒートマップを帯域・条件ごとに分けて全件添付する。被験者の順はfold・group・匿名subject IDで固定し、成績順に並べない。本文で縮小して読めない場合は、このパネルを補足ページに展開する。値の良い被験者や部位対だけに置き換えない。

fold別の符号・大きさも同じ元データから補足し、foldはモデルを識別する印として使う。5foldをN=5の独立反復とする検定はしない。「集団で共通」は、中央値、正の割合、個別分布、人数を併せた記述とする。

### N-F3：絶対lagを保持した上で中心化する

**A：絶対lag。** 横軸はtarget時点から遡るlagのms、元データにframeも保持する。縦軸は全候補のcell-Gの被験者間中央値、0の水平線を引く。全56部位対（8領域の場合）を固定順の小パネルで示し、結果による上位抽出はしない。被験者別曲線・E_cell・E_Selfも補足データに残す。h=1のτ=1は予測起点の現在観測を意味し、lag=0の予測入力を追加しない。

実際の最大lag L/fを端点に表示する。異なるfpsの系列を同じframe軸でpoolせず、同一fpsで実行する現推薦に従う。端点に最大Gがある場合は「この範囲で終端未確認」と記述する。滑らかな曲線補間によって実際より細かい時間分解能を示さない。

**B：中心化応答。** 横軸Δ、縦軸R。各edgeについてSelf＋単一sourceブロックを使い、次の順で集約する。

```text
各被験者・選択edgeの誤差差D(Δ)
→ 同一source→targetの複数選択lagを平均
→ 被験者内の部位対を等重み平均
→ 被験者間中央値
```

全Δで同じedge・部位対・被験者・supportを使う。対称gridの全点が範囲内にあるedgeだけを対象とし、境界edgeをclip/wrapしない。約±100 msは現推薦であり、採用fpsとfreezeされたMから実幅を表記する。

R(0)=0は定義上の固定点なので、強調色・有意マーク・「最適lag」のラベルを付けない。正のRはずらしたときの悪化、負は周辺lagの方が低誤差。AのGとは正の意味が異なるため、別の縦軸名・パネルにする。

全選択edge数、対称grid適格数、境界除外数・率、計算失敗数、部位対数、被験者数、独立group数をN-T3に併記する。絶対lagで選択されたedgeを消さず、中心化に使えた部分集団を明示する。

### N-F4：性能比較を一つの図へ統合する

Aは4条件のEを被験者点＋中央値＋名目区間で表示する。全顔は8領域すべてが評価可能な被験者について領域等重みで先に平均する。target別結果も全件保存し、全顔不能だからといってtarget別結果を捨てない。

Bは同一被験者・同一supportでの次の対応差を示す。モデル別中央値を引いた値ではなく、被験者ごとの差を計算してから中央値を取る。

| 対応差 | 正の値の意味 |
|---|---|
| E_Persistence − E_Self | Selfが持続予測を改善 |
| E_Self − E_Full | 全他部位履歴の追加で改善 |
| E_Self − E_PCMCI-block | 選択ブロックの同時入力で改善 |
| E_Full − E_PCMCI-block | PCMCI-blockがFullより低誤差 |

target別の点・区間は同図の補足パネル、入力数はN-T2にまとめる。単独のPCMCI対Self図、誤差分布図、target別gain図、性能–疎性図を重複して本文に並べない。非有意を同等とする判定、Full同等ライン、疎性の合格領域は置かない。

空選択ではPCMCI-block=Selfなので対応差0を有効な予測結果として残す。これはN-F5の空集合をZ=0にする扱いとは異なる。

### N-F5：Enrichmentをモデル性能と混ぜない

target別に次を計算する。cとfoldの添字は省略する。

```math
A_{sel}(s,j)=\operatorname{mean}_{e\in S_j}G_s(e),\qquad
A_{rand}(s,j,r)=\operatorname{mean}_{e\in A_{j,r}}G_s(e),
\qquad Z_{s,j}=A_{sel}(s,j)-\frac{1}{1000}\sum_{r=1}^{1000}A_{rand}(s,j,r).
```

Aはtarget別のZ_s,jの被験者点・中央値・名目区間。Bは各被験者で評価可能な選択targetのZを等重み平均したZ_sの点・中央値・名目区間。「全顔Enrichment」と呼ばず、foldごとの使用target集合を示す。target別中央値を平均してBを作らない。

Cは被験者×targetごとの1,000個のA_randの分布にA_selとランダム集合平均を重ねる補足パネルとする。全分布を保存し、紙面では固定ID順のページへ展開する。このパネルの横方向の差がその被験者・targetのZになる。被験者をpoolしたランダム分布から集団Zを作らない。反復は同じfoldのtest被験者で共通の集合IDを指し、1,000個を1,000人と数えない。

比較はブロック数と実scalar成分数を一致させる。Selfは抽出しない。集合内重複なし、選択集合との重なり・反復間重複ありという現推薦に従う。選択集合が候補全部ならZ=0と識別余地なしを表示する。空集合は評価不能。1,000反復の一部が失敗したとき、成功分だけで期待値を代用しない。

参照分布の順位を厳密な置換p値として表示しない。正のZでも、選択平均G自体が負の場合は「悪化の小さいcellに相対的に濃縮」であり、Selfを改善したとはいえない。A_sel、ランダム集合平均、ZをN-T3に並べてこの違いを読めるようにする。

## 4. 必須の補足2図

**N-SF1：測定・品質・support。** 採用点と正規化参照点を区別する配置図、条件別の元時間から共通supportまでの減少、被験者別の欠損・採用可能率・観測変位振幅を示す。振幅はQCの記述であり、予測改善を振幅で割る主指標は追加しない。低振幅を高精度測定の証拠にしない。顔上の図は採用topologyを確定後に実際の対応表から作る。

**N-SF2：発見安定性。** 領域対×帯域と領域×lagの選択頻度をouter-fold・条件別に示す。帯域選択は「帯域内で1ブロック以上選択」とし、帯域が広いほど選択機会が違うので帯域内候補数を添える。元outer-trainの選択状態と100再探索の頻度を分ける。held-outのGを色に混ぜない。

予定反復数、選択可能反復数N、成功数、選択数k、失敗数fを保存する。全対象反復成功ならk/N。失敗が残る場合は `[k/N, (k+f)/N]` の不明幅を示し、通常の頻度や95%区間と呼ばない。N=0は評価不能。70%等で非表示にせず、全候補を残す。foldの出現回数も機会数つきで併記し、学習集合の重複がある探索の記述として扱う。

## 5. 全図表で共通にする集約・表示

1. **supportを照合する。** 同じ被験者・条件・foldの比較で行・target点集合を一致させる。行数だけではなくsupport ID/hashで照合する。各図のN・group数・使用target/edge集合を元表へ追跡できるようにする。
2. **不確かさを限定して記述する。** 現推薦の区間は、固定OOF結果に対する被験者構成の変動を示す名目95% bootstrap区間。outer-fold内で独立groupを復元抽出し、10,000回、全被験者・cell・曲線を一緒に扱い、全図表で抽出indexを共用する。評価可能groupが10未満なら個別値と点推定を示し、区間は評価不能とする。
3. **曲線の帯は点ごとの名目区間。** 同時区間や多重比較補正済みと表示しない。選択・学習をやり直す変動を含む区間でもない。CVの学習集合重複による誤差の依存は、素朴な分散推定を過小にし得る。[Bengio & Grandvalet, 2004](https://jmlr.org/papers/v5/grandvalet04a.html)
4. **有意性を図の選別に使わない。** 検定を行わない現推薦に合わせ、星印、p/q値列、有意セル数、CIによる表示の足切りは不要。G・Zが負、Rが平坦でも同じ規則で描く。
5. **状態を失わない。** 候補外、空選択、データ不足、計算失敗、観測ゼロを区別する。不能を0や無印の空白に置き換えず、status/reasonと分母を表示する。予定反復が欠けた解析を完了扱いにしない。
6. **図から数値へ辿れるようにする。** 数値表を先に確定し、その保存値から描画する。metric ID、単位、集約順、protocol/schema/config/code/dataの版、support、seed、出典表とhashをregistryへ残す。N-ST2はそれらの索引も持つ。

PCMCI+は条件付き独立性に基づく探索法で、原著の因果的な整合性の議論には因果的十分性等の仮定がある。[Runge, 2020](https://proceedings.mlr.press/v124/runge20a.html) 本図表ではsource→targetを遅延予測関係として記述し、顔上の矢印を直接的な筋肉間因果、lagを生理的伝達時間と呼ばない。

## 7. 今回の再考から実装へ移す際の確認事項

現コードの `analysis_pipeline.py` は `PRIMARY_METRIC = "velocity_rmse"` を固定し、`metrics.py` の主計算経路も速度RMSEである。Scientific Freezeはv6のcommon-shift、旧Null条件、matched 100回を保持する。既存trackerのCode/Testチェックはこの移行元に対する履歴であり、本書の新指標・新集約を実装済みとする証拠ではない。

図のタイトル・軸ラベルだけを変更して旧結果を使うことはできない。採用protocolで次を順に確認する。

- 正規化変位の予測・正解と点のx/y対応から新Eを計算し、Ridgeのinner選択スコアも同じ主誤差へ揃える。速度RMSEの既存集計値から新Eへ変換しない。
- 比較可能な予測・support・候補・セル誤差が揃った後、G、集合平均、部位対を先に平均する中心化応答、groupによる区間を計算する。
- source CSV、caption、registry、図表必須一覧を同じversionへ接続する。旧artifactは新版の入力として受理しない。実データ未取得の値・点・fpsを架空の確定値で埋めない。

受入時は、同一supportの差、帯域平均後の被験者中央値、空選択の扱い、1,000集合の算術平均、中心化の集約順、Δ=0、境界除外、人数・group数・反復数、図の色と保存値の一致を確認する。mockは式・描画の確認に限定し、科学的結果には使わない。

この再構成によって、全候補の予測情報を先に評価し、選択法の良し悪しを独立に読める。主成果は「PCMCIが勝った図」や有意な矢印の数ではなく、どの部位対・時間帯でどれだけの改善があり、何人に共通し、何が評価できなかったかを一貫した新指標で示すことである。
